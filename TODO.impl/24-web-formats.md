# 24 — Web font formats: WOFF2 indexing + desktop→web transcoding

Priority: 1

## Deliverable

Completes the "Future" items of TODO 22 and the WOFF2 gap of TODO 5:

- `src/fonts/sfnt/assemble.ts`: shared SFNT assembler (extracted from the
  private `assembleSfnt` in fontFile.ts); `SfntFont.tables()` exposes
  `{ tag, data }[]` for encoders.
- `src/fonts/woff/woff2.ts`: WOFF2 decode (header + table directory with
  known-tag indices and uintBase128, single brotli stream via node zlib) that
  reconstructs untransformed tables (name, fvar, ...) for metadata indexing;
  glyf/loca/hmtx transforms are consumed but not rebuilt (not needed for
  metadata). WOFF2 encode for transcoding: null transforms for all tables,
  brotli-compressed data block.
- `src/fonts/woff/woff1.ts`: WOFF1 encode (per-table zlib) + move of the
  WOFF1 decoder from fontFile.ts.
- `FontFile.fromBytes`: route woff/woff2 through the decoders — woff2 fonts
  become indexable (family, subfamily, variable axes).
- `TranscoderRegistry`: register a real `WoffTranscoder` (ttf/otf → woff,
  ttf/otf → woff2), completing the desktop→web conversion pipeline gated by
  `TranscodeLicenseNotAcceptedError`.

## Acceptance

- Round-trip specs: sfnt → woff → decode → same metadata; sfnt → woff2 →
  decode → same metadata.
- Cross-validation against reference fixtures generated by fontTools
  (woff2-flavor) committed under `spec/fixtures/fonts/` — our decoder must
  read fontTools-produced woff2; fontTools must parse our woff2 (validated
  when generating the fixture).
- Installer spec: `--format woff2` on a formula without format constraints
  transcodes and installs a decodable woff2.
- Installed-index spec: a woff2 font in the fontist dir is indexed and
  findable.
